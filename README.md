# Sistema Bancario Simple

Sistema bancario simple desarrollado en **Java** utilizando **JavaFX** para la interfaz gráfica, **H2** como base de datos local y **JUnit 5** para pruebas automatizadas.  
El proyecto está estructurado bajo el patrón **MVC (Model–View–Controller)** para separar responsabilidades y facilitar el mantenimiento y la escalabilidad.

## 🛠️ Tecnologías utilizadas

- **Java**: Amazon Corretto 22  
- **JavaFX**: versión 21  
- **Maven**: gestión de dependencias y build  
- **Base de datos**: H2 (embebida/local)  
- **Testing**: JUnit 5  
- **UI adicional**:
  - ControlsFX
  - FormsFX

## Arquitectura

El proyecto sigue el patrón **MVC**

## Funcionalidades principales

- Gestión básica de un sistema bancario
- Persistencia de datos usando H2 en modo local
- Interfaz gráfica con JavaFX
- Pruebas unitarias automatizadas con JUnit
- Separación clara de responsabilidades usando MVC

## Requisitos

- **Java JDK 22** (Amazon Corretto recomendado)
- **Maven 3.8+**
- Sistema operativo compatible con JavaFX

## Pruebas: mvn test
